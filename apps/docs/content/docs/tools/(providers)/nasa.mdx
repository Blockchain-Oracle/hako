## NASA Astronomy Picture of the Day [#apod]

`nasa/apod` · **$0.001** per call (local) · Science & Health

**NASA's Astronomy Picture of the Day for a date (or today): title, explanation, image URL and credit.**

Returns one APOD: its title, the astronomer-written explanation, the image (or video embed) URL, the credit line and whether that credit claims copyright, plus the page link. Any date since 1995-06-16; omit the date for the latest. Many APOD images belong to their photographers: show or link them with the credit, and do not treat them as public domain. For asteroid fly-bys use nasa/asteroids.

Related: [`nasa/asteroids`](/docs/tools/nasa#asteroids), [`wikipedia/summary`](/docs/tools/wikipedia#summary).

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `date` | string (date) | no | YYYY-MM-DD from 1995-06-16 on; omit for the latest picture. |

## NASA Near-Earth Asteroids [#asteroids]

`nasa/asteroids` · **$0.001** per call (local) · Science & Health

**Asteroids passing Earth over up to 7 days: miss distance, speed, size and hazard flag, closest first.**

Reads NASA's NeoWs feed (JPL CNEOS data) for up to a week and returns the count, how many are flagged potentially hazardous, and the closest approaches with time, miss distance (km and lunar distances), speed, estimated diameter and JPL's page. 'Potentially hazardous' is an orbital classification, not a prediction of impact. It does not compute impact probabilities; JPL's Sentry list is flagged per object.

Related: [`nasa/apod`](/docs/tools/nasa#apod).

### Input [#asteroids-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `start_date` | string (date) | no | YYYY-MM-DD; defaults to today (UTC). |
| `end_date` | string (date) | no | YYYY-MM-DD, at most 7 days after start\_date; defaults to it. |
| `hazardous_only` | boolean | no | Only objects NASA flags as potentially hazardous. Default `false`. |
| `limit` | integer | no | From 1 to 25. Default `10`. |
