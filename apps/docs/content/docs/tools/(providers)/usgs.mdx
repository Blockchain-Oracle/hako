## USGS Recent Earthquakes [#earthquakes]

`usgs/earthquakes` · **$0.001** per call (local) · Weather & Earth, Science & Health

**Recent earthquakes worldwide or within a radius of a point: magnitude, place, time, depth, tsunami flag.**

Lists earthquakes from the USGS real-time catalogue for the past hour, day, week or 30 days, above a minimum magnitude, newest or strongest first; give latitude/longitude (and radius\_km) to search around a place. Each row has UTC time, magnitude, place, depth, coordinates, the tsunami flag, PAGER alert level and the USGS event page. Coverage is global for M4.5+, and dense for smaller quakes mainly in the US. It does not forecast quakes or issue tsunami warnings; check official agencies for those.

Related: [`openweather/current`](/docs/tools/openweather#current), [`wikipedia/summary`](/docs/tools/wikipedia#summary).

### Input [#earthquakes-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `period` | string | no | How far back: the past hour, day, week or 30 days. One of `hour`, `day`, `week`, `month`. Default `"day"`. |
| `min_magnitude` | number | no | From 0 to 10. Default `2.5`. |
| `latitude` | number | no | Centre of a search circle. From -90 to 90. |
| `longitude` | number | no | From -180 to 180. |
| `radius_km` | number | no | Circle radius around the point. At most 20001.6. Greater than 0. Default `300`. |
| `order` | string | no | One of `newest`, `strongest`. Default `"newest"`. |
| `limit` | integer | no | From 1 to 50. Default `10`. |
