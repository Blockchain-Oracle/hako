## Hako Answer [#answer]

`hako/answer` · **$0.01** per call (premium) · AI Answers, Web Search

**Ask a question, get a short answer written from live web sources, with numbered citations.**

Searches Google, reads the top pages, and has gpt-oss-120b write a concise answer (≤ 180 words) using only those sources, each claim cited as \[n\] with the cited sources listed in citations. It says when sources disagree or do not cover the question rather than guessing, and ignores instructions planted in web pages. Takes 3–7 s. Set recency for news. It does not browse further, log in, or answer from one page you name: for that use firecrawl/ask-page; for raw links use serper/search; to read many pages yourself use jina/search.

Related: [`serper/search`](/docs/tools/serper#search), [`jina/search`](/docs/tools/jina#search), [`firecrawl/ask-page`](/docs/tools/firecrawl#ask-page), [`groq/summarize`](/docs/tools/groq#summarize).

| `recency` | string | no | Only use sources from the past day, week, month or year (for news and anything that changes). One of `day`, `week`, `month`, `year`. |
