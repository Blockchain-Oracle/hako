## Dictionary Definition [#define]

`dictionary/define` · **$0.001** per call (local) · Words & Language

**Define an English word: pronunciation (IPA + audio), meanings by part of speech, examples, synonyms.**

Looks up one English word in the Free Dictionary API (Wiktionary data) and returns its phonetic spelling, a pronunciation audio URL, and up to six meanings grouped by part of speech, each with definitions, example sentences, synonyms and antonyms. English only; an unknown word answers found=false. For 'what's the word for…', rhymes or sound-alikes use datamuse/words; for encyclopaedic topics use wikipedia/summary.

Related: [`datamuse/words`](/docs/tools/datamuse#words), [`wikipedia/summary`](/docs/tools/wikipedia#summary).
