## Wikipedia On This Day [#on-this-day]

`wikipedia/on-this-day` · **$0.001** per call (local) · Knowledge & Reference

**Historical events, births, deaths or holidays for a calendar day, from Wikipedia's 'On this day'.**

Returns what happened on a month/day across history (newest year first), each with the year, a one-line description and the main article. 'selected' is the curated short list; 'events', 'births' and 'deaths' are the long lists (slower when not cached). It is keyed by calendar day, not by year: it will not list everything that happened in 1969. For one topic's history use wikipedia/summary or hako/answer.

Related: [`wikipedia/summary`](/docs/tools/wikipedia#summary), [`hako/answer`](/docs/tools/hako#answer).

### Input [#on-this-day-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `month` | integer | no | 1–12; defaults to today (UTC). From 1 to 12. |
| `day` | integer | no | 1–31; defaults to today (UTC). From 1 to 31. |
| `kind` | string | no | Curated highlights, events, births, deaths or holidays. One of `selected`, `events`, `births`, `deaths`, `holidays`. Default `"selected"`. |
| `limit` | integer | no | From 1 to 30. Default `10`. |
| `lang` | string | no | Wikipedia language edition, e.g. 'en', 'fr', 'ja'. Pattern `^[a-z]{2,3}(-[a-z]{2,8})?$`. Default `"en"`. |

### Example [#on-this-day-example]

```json title="Input"

  "limit": 10
}
```

## Wikipedia Search [#search]

`wikipedia/search` · **$0.001** per call (local) · Knowledge & Reference

**Find Wikipedia articles by keywords: titles, short descriptions and matching snippets.**

Full-text search over one Wikipedia edition, ranked by Wikipedia's own relevance. Returns article titles, URLs, the short description and a snippet around the match. Use it to find the exact title, then wikipedia/summary for the lead paragraph. It searches Wikipedia only; for the open web use serper/search or firecrawl/search, and for structured entities use wikidata/search.

Related: [`wikipedia/summary`](/docs/tools/wikipedia#summary), [`wikidata/search`](/docs/tools/wikidata#search), [`serper/search`](/docs/tools/serper#search).

### Input [#search-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |

| `lang` | string | no | Wikipedia language edition, e.g. 'en', 'fr', 'ja'. Pattern `^[a-z]{2,3}(-[a-z]{2,8})?$`. Default `"en"`. |

## Wikipedia Article Summary [#summary]

`wikipedia/summary` · **$0.001** per call (local) · Knowledge & Reference

**The lead paragraph of a Wikipedia article: extract, short description, thumbnail and page URL.**

Looks an article up by exact title (redirects are followed, so 'JFK' reaches John F. Kennedy) and returns its lead-section extract in plain text, the one-line description, a thumbnail and the Wikidata id. It does not search: if you are unsure of the title use wikipedia/search first. It returns only the lead, not the whole article; for the full page use firecrawl/scrape or jina/read on the URL. For structured facts (dates, population, website) use wikidata/entity with the returned wikidata\_id.

Related: [`wikipedia/search`](/docs/tools/wikipedia#search), [`wikidata/entity`](/docs/tools/wikidata#entity), [`firecrawl/scrape`](/docs/tools/firecrawl#scrape).

### Input [#summary-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `title` | string | yes | Article title, e.g. 'Alan Turing'. 1–255 characters. |
| `lang` | string | no | Wikipedia language edition, e.g. 'en', 'fr', 'ja'. Pattern `^[a-z]{2,3}(-[a-z]{2,8})?$`. Default `"en"`. |
