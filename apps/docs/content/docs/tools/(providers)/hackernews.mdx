## Hacker News Search [#search]

`hackernews/search` · **$0.001** per call (local) · News, Developer

**Search Hacker News stories, comments, Ask HN and Show HN posts by relevance or newest first.**

Full-text search over all of Hacker News through Algolia, with typo tolerance off so results contain your exact words. Returns each item's title, link (the story's URL, or the HN thread for comments and text posts), points, comment count, author, time and HN link; comments and Ask HN bodies come as plain text cut to 600 characters. Filter to the last N days or sort by date for 'what is HN saying now'. It does not fetch the linked article (use firecrawl/scrape or jina/read) and covers HN only; for general headlines use hako/news or serper/news.

Related: [`hako/news`](/docs/tools/hako#news), [`serper/news`](/docs/tools/serper#news), [`firecrawl/scrape`](/docs/tools/firecrawl#scrape), [`github/search-repos`](/docs/tools/github#search-repos).

### Input [#search-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | string | yes | Words to find (exact spelling). 1–200 characters. |
| `type` | string | no | story, comment, ask\_hn or show\_hn. One of `story`, `comment`, `ask_hn`, `show_hn`. Default `"story"`. |
| `sort` | string | no | relevance (points weigh in) or date (newest first). One of `relevance`, `date`. Default `"relevance"`. |
| `since_days` | integer | no | Only items from the last N days. From 1 to 3650. |
| `limit` | integer | no | Items to return. From 1 to 20. Default `10`. |
