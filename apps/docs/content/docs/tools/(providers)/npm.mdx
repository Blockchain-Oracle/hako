## npm Package [#package]

`npm/package` · **$0.001** per call (local) · Developer

**An npm package's latest version, licence, repository, deprecation notice and weekly downloads.**

Reads the registry's document for the package's `latest` dist-tag and returns its version, description, licence, homepage, repository URL, maintainer and dependency counts, required engines (Node version), the deprecation message if the latest version is deprecated, plus last week's download count and the latest publish time when npm reports them. It does not list every version or audit dependencies: use depsdev/package for version history and depsdev/version for licences and security advisories; use github/repo for the repository's activity.

Related: [`depsdev/package`](/docs/tools/depsdev#package), [`depsdev/version`](/docs/tools/depsdev#version), [`github/repo`](/docs/tools/github#repo), [`pypi/package`](/docs/tools/pypi#package).
