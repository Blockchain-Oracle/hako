## Google News Headlines [#headlines]

`google-news/headlines` · **$0.001** per call (local) · News

**Today's top stories, or one section (business, technology, sports…), for any country edition.**

The current Google News front page or one of its sections (world, nation, business, technology, entertainment, sports, science, health) for a country and language edition, up to 30 headlines with publisher and time. Use it for 'what's in the news in Nigeria today' or 'top tech stories'; to search a subject use google-news/search.

Related: [`google-news/search`](/docs/tools/google-news#search), [`hako/news`](/docs/tools/hako#news).

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `country` | string | no | ISO 3166-1 alpha-2 edition: US, GB, NG, IN… Pattern `^[A-Za-z]{2}$`. Default `"US"`. |
| `language` | string | no | ISO 639-1 language: en, fr, es, pt, de… Pattern `^[a-z]{2}$`. Default `"en"`. |
| `limit` | integer | no | From 1 to 30. Default `10`. |
| `topic` | string | no | top (front page) or a section: world, nation, business, technology, entertainment, sports, science, health. One of `top`, `world`, `nation`, `business`, `technology`, `entertainment`, `sports`, `science`, `health`. Default `"top"`. |

## Google News Search [#search]

`google-news/search` · **$0.001** per call (local) · News

**Search news from thousands of publishers by keyword, country, language and recency (keyless).**

Searches Google News and returns up to 30 articles, newest and most relevant first: headline, publisher, publisher site, publication time and a link that redirects to the article. Filter by edition (country + language) and recency (day, week, month); Google's quotes and OR operators work. Headlines only, no article text: read one with jina/read or firecrawl/scrape. For Google's ranked news with snippets and images use serper/news; for tech-community discussion use hackernews/search.

Related: [`google-news/headlines`](/docs/tools/google-news#headlines), [`serper/news`](/docs/tools/serper#news), [`jina/read`](/docs/tools/jina#read).

### Input [#search-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `country` | string | no | ISO 3166-1 alpha-2 edition: US, GB, NG, IN… Pattern `^[A-Za-z]{2}$`. Default `"US"`. |
| `language` | string | no | ISO 639-1 language: en, fr, es, pt, de… Pattern `^[a-z]{2}$`. Default `"en"`. |
| `limit` | integer | no | From 1 to 30. Default `10`. |
| `query` | string | yes | Keywords; quotes and OR work as on Google: '"MoonPay" OR Coinbase'. 2–200 characters. |
| `recency` | string | no | Only articles from the last day, week or month. One of `any`, `day`, `week`, `month`. Default `"any"`. |
