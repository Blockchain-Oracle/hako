## IPinfo IP Lookup [#lookup]

`ipinfo/lookup` · **$0.005** per call (standard) · Internet & Network

**Who runs an IP address and where: country, continent, ASN, network name and domain.**

Looks up one public IPv4 or IPv6 address in IPinfo's Lite database: ISO country and continent, and the autonomous system that announces it (ASN such as AS15169, its name and domain), plus whether it is anycast. Country-level only: no city, coordinates, ISP contact, VPN/proxy flags or hostnames. Private, loopback and reserved ranges are rejected as invalid input.

### Input [#lookup-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `ip` | string | yes | A public IPv4 or IPv6 address, e.g. '8.8.8.8' or '2606:4700::1111'. 2–45 characters. |
