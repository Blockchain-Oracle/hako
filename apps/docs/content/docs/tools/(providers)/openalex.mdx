## OpenAlex Authors Search [#authors]

`openalex/authors` · **$0.001** per call (local) · Research & Papers

**Find researchers by name: works count, citations, h-index, last known institution and main topic.**

Searches OpenAlex's disambiguated author profiles, so one person's papers are grouped under one id. Use the counts and institution to pick the right person among namesakes. It does not list the author's papers; search openalex/works with the author's name or a topic for that.

Related: [`openalex/works`](/docs/tools/openalex#works).

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | string | yes | An author's name, e.g. 'Geoffrey Hinton'. 2–200 characters. |
| `k` | integer | no | From 1 to 10. Default `5`. |

## OpenAlex Work [#work]

`openalex/work` · **$0.001** per call (local) · Research & Papers

**One scholarly work by DOI or OpenAlex id: metadata, abstract, topic, citations, retraction flag.**

Looks up a single work by DOI, OpenAlex id or arXiv id and returns its title, authors, venue, date, type, citation and reference counts, primary topic, open-access link, a retraction flag and the abstract when OpenAlex has one (publishers withhold many). An unknown id answers found=false. arXiv preprints carry partial citation data (a note says so). For the publisher's own record (licence, update and retraction notices) use crossref/work; to read inside the paper use firecrawl/read-paper.

Related: [`crossref/work`](/docs/tools/crossref#work), [`openalex/works`](/docs/tools/openalex#works), [`firecrawl/read-paper`](/docs/tools/firecrawl#read-paper), [`firecrawl/related-papers`](/docs/tools/firecrawl#related-papers).

## OpenAlex Works Search [#works]

`openalex/works` · **$0.001** per call (local) · Research & Papers

**Search 250M+ scholarly works: title, authors, year, venue, DOI, citation count and open-access link.**

Keyword search over the titles and abstracts of papers, books, datasets and theses from every discipline, sortable by relevance, citations or date and filterable by year and open access. Each result carries an OpenAlex id and DOI for openalex/work (abstract, topic, retraction flag) or crossref/work. It ranks by keywords, not meaning: for semantic search over arXiv-style papers use firecrawl/research-papers; for newest preprints use arxiv/search. It does not return full text.

Related: [`openalex/work`](/docs/tools/openalex#work), [`crossref/search`](/docs/tools/crossref#search), [`arxiv/search`](/docs/tools/arxiv#search), [`firecrawl/research-papers`](/docs/tools/firecrawl#research-papers).

### Input [#works-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | string | yes | Words in the title, abstract or full text. 2–500 characters. |
| `k` | integer | no | Works to return. From 1 to 10. Default `5`. |
| `sort` | string | no | One of `relevance`, `most_cited`, `newest`. Default `"relevance"`. |
| `year_from` | integer | no | From 1000 to 2100. |
| `year_to` | integer | no | From 1000 to 2100. |
| `open_access_only` | boolean | no | Only works with a free full-text copy. Default `false`. |
