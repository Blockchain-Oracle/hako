## PyPI Package [#package]

`pypi/package` · **$0.001** per call (local) · Developer

**A Python package's latest version, licence, supported Python, links, upload time, yanked flag and CVEs.**

Reads PyPI's JSON API for a project (its latest release, or the version you name) and returns the version, summary, licence (SPDX expression when declared, else the licence classifier), requires-python, how many required dependencies it declares, its project links (source, docs, changelog), when the release was uploaded, whether it is yanked and why, and the known vulnerabilities PyPI lists for that release (OSV ids with the versions that fix them). It does not list every release or read the README: use depsdev/package for version history and github/repo for repository activity.

Related: [`depsdev/package`](/docs/tools/depsdev#package), [`depsdev/version`](/docs/tools/depsdev#version), [`github/repo`](/docs/tools/github#repo), [`npm/package`](/docs/tools/npm#package).

### Input [#package-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | yes | PyPI project name, e.g. 'httpx'. 1–100 characters. Pattern `^[A-Za-z0-9](?:[A-Za-z0-9._-]*[A-Za-z0-9])?$`. |
| `version` | string | no | A specific release (default: the latest). At most 64 characters. Pattern `^[A-Za-z0-9][A-Za-z0-9._+!-]*$`. |
