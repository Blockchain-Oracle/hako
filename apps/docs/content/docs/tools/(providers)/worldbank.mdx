## World Bank Indicator [#indicator]

`worldbank/indicator` · **$0.001** per call (local) · Finance & Markets, Government & Law

**Yearly values of a World Bank indicator (GDP, population, inflation…) for a country, newest first.**

Returns the most recent non-empty yearly values of one World Development Indicator for one country or aggregate (world, EU, income groups), with the indicator's full name and the data's last update. Pass a WDI code or a friendly alias (gdp, gdp\_per\_capita, gdp\_growth, population, inflation, unemployment, life\_expectancy, internet\_users, co2\_per\_capita, gini, …). Values are annual and lag 1–2 years; it has no monthly, live market or forecast data. An unknown country or code answers found=false. A query nobody has asked recently can take several seconds upstream; repeats are cached for a day.

Related: [`wikidata/entity`](/docs/tools/wikidata#entity), [`hako/answer`](/docs/tools/hako#answer).

### Input [#indicator-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `country` | string | yes | ISO 3166 alpha-2 or alpha-3 code ('BR', 'BRA'), or a region such as 'WLD' (world) or 'EUU' (European Union). Pattern `^[A-Za-z0-9]{2,3}$`. |
| `indicator` | string | yes | A WDI code such as 'NY.GDP.MKTP.CD', or one of: gdp, gdp\_per\_capita, gdp\_growth, population, inflation, unemployment, life\_expectancy, internet\_users, co2\_per\_capita, gini, fdi\_inflows, exports\_pct\_gdp, government\_debt\_pct\_gdp, urban\_population\_pct. 2–40 characters. |
| `years` | integer | no | How many most recent non-empty years. From 1 to 60. Default `10`. |
