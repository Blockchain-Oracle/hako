## YouTube Video Info [#video]

`youtube/video` · **$0.001** per call (local) · Content Extraction

**Title, channel and thumbnail of a public YouTube video from its link or id (oEmbed).**

Resolves any YouTube link (watch, youtu.be, shorts, embed, live) or bare video id to the video's title, channel name and URL, thumbnail and embed link, via YouTube's public oEmbed endpoint. Metadata only: it does not return transcripts, descriptions, view counts or comments (transcripts are not offered by Hako). Private, removed and embedding-disabled videos answer not found. To find videos about a topic use serper/search.

Related: [`serper/search`](/docs/tools/serper#search), [`firecrawl/scrape`](/docs/tools/firecrawl#scrape).
