## GitHub Latest Release [#latest-release]

`github/latest-release` · **$0.001** per call (local) · Developer

**The newest published (non-draft, non-prerelease) release of a GitHub repository, with its notes.**

Returns the repository's latest full release as GitHub defines it (drafts and prereleases are skipped): tag, title, publish time, link and the first 2,000 characters of the release notes. Repositories that only push git tags, never Releases, answer not found: check npm/package or pypi/package for the latest published version instead.

Related: [`github/repo`](/docs/tools/github#repo), [`npm/package`](/docs/tools/npm#package), [`pypi/package`](/docs/tools/pypi#package), [`depsdev/package`](/docs/tools/depsdev#package).

## GitHub Repository [#repo]

`github/repo` · **$0.001** per call (local) · Developer

**One public GitHub repository: description, stars, forks, open issues, licence, topics, last push.**

Looks up a public repository by owner/name and returns what an agent needs to judge it: description, stars, forks, open issues (GitHub includes open pull requests in that count), SPDX licence, default branch, main language, topics, homepage, whether it is archived or a fork, and when it was created and last pushed. It does not read files, issues or the README: use firecrawl/developer-search for those, and github/latest-release for the newest release notes. Private repositories answer not found.

Related: [`github/latest-release`](/docs/tools/github#latest-release), [`github/search-repos`](/docs/tools/github#search-repos), [`firecrawl/developer-search`](/docs/tools/firecrawl#developer-search), [`depsdev/package`](/docs/tools/depsdev#package).

## GitHub Repository Search [#search-repos]

`github/search-repos` · **$0.001** per call (local) · Developer

**Find public GitHub repositories by keywords, language and qualifiers, sorted by match, stars or update.**

Searches GitHub's repository index (names, descriptions, topics, README text) and returns up to 10 repositories with stars, forks, language and last push. Accepts GitHub search qualifiers ('topic:', 'stars:\>', 'pushed:\>2026-01-01'). It finds repositories, not code or issues: for 'how do I' and error-message questions use firecrawl/developer-search; to open one result use github/repo.

Related: [`github/repo`](/docs/tools/github#repo), [`firecrawl/developer-search`](/docs/tools/firecrawl#developer-search), [`npm/package`](/docs/tools/npm#package), [`pypi/package`](/docs/tools/pypi#package).

### Input [#search-repos-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | string | yes | Words to match in names, descriptions and topics; GitHub qualifiers such as 'topic:cli' or 'stars:\>1000' work too. 1–256 characters. |
| `language` | string | no | Only repositories in this language, e.g. 'Rust'. At most 40 characters. |
| `sort` | string | no | best-match, most stars, or most recently updated. One of `best-match`, `stars`, `updated`. Default `"best-match"`. |
| `limit` | integer | no | Repositories to return. From 1 to 10. Default `5`. |

### Example [#search-repos-example]

```json title="Input"
{
  "query": "http client",
  "language": "Python",
  "sort": "stars",
  "limit": 5
}
```
