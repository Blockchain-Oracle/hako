## Firecrawl Ask a Page [#ask-page]

`firecrawl/ask-page` · **$0.01** per call (premium) · AI Answers, Content Extraction

**Ask a question about one web page and get a short answer read from that page.**

Reads the page in a browser and answers the question from its content only (it does not search the web). Good for 'what does this pricing page say about X'. For questions that need several sources use hako/answer.

## Firecrawl Site Map [#map]

`firecrawl/map` · **$0.005** per call (standard) · Content Extraction

**List the URLs on a website (optionally only those relevant to a few words), fast.**

Discovers a site's URLs without scraping them, with titles where known; with search, the URLs most relevant to those words come first. Without search it reads the sitemap (about 1 s) and crawls only a site that has none. A first map of a large site can take up to 8 s and may time out (not charged): start from a narrower URL then. Use it to find the right page, then read that page with firecrawl/scrape.

Related: [`firecrawl/scrape`](/docs/tools/firecrawl#scrape).

## Firecrawl Scrape [#scrape]

`firecrawl/scrape` · **$0.005** per call (standard) · Content Extraction

**Turn any URL (including JavaScript-heavy pages and PDFs) into clean markdown.**

Renders the page in a real browser and returns its main content as markdown with the title, description, language and the HTTP status the site answered. Works on single-page apps and PDFs. ## Firecrawl Web Search [#search]

`firecrawl/search` · **$0.01** per call (premium) · Web Search, News

**Search the live web or news and optionally get every result's page as markdown in the same call.**

Live web or news search (not a cached index): titles, URLs and snippets, newest-first when a time range is set. Set with\_content to receive each result's main content as markdown, which saves a separate scrape per page. For a single known URL use firecrawl/scrape; for a cited answer to a question use hako/answer; for cheaper plain Google results use serper/search.

Related: [`serper/search`](/docs/tools/serper#search), [`firecrawl/scrape`](/docs/tools/firecrawl#scrape), [`hako/answer`](/docs/tools/hako#answer).

### Input [#search-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | string | yes | What to search for, in plain words. 1–500 characters. |
| `limit` | integer | no | Results to return. From 1 to 10. Default `5`. |
| `source` | string | no | web pages or news articles. One of `web`, `news`. Default `"web"`. |
| `time_range` | string | no | Only results from the last day/week/month/year. One of `day`, `week`, `month`, `year`. |
| `country` | string | no | ISO country code, e.g. 'us'. 2–2 characters. |
| `with_content` | boolean | no | Also return each result's page as markdown (costs more). Default `false`. |
