## Frankfurter Currency Converter [#convert]

`frankfurter/convert` · **$0.001** per call (local) · Finance & Markets

**Convert an amount between two currencies at the latest (or a dated) central-bank rate.**

Converts an amount from one currency to another with the rate's publication date, at Frankfurter's blended central-bank rate or one bank's fixing (provider, e.g. ECB). Reference rates: a bank or card will charge a spread on top. For several target currencies use frankfurter/rates; to check the rate against several independent banks use hako/fx.

Related: [`frankfurter/rates`](/docs/tools/frankfurter#rates), [`hako/fx`](/docs/tools/hako#fx).

### Input [#convert-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `amount` | number | yes | How much of the source currency. Greater than 0. |
| `base` | string | yes | Convert from this currency. 3–3 characters. Pattern `^[A-Za-z]{3}$`. |
| `quote` | string | yes | Convert to this currency. 3–3 characters. Pattern `^[A-Za-z]{3}$`. |
| `date` | string (date) | no | Use the rate of this day (default: latest). |
| `provider` | string | no | One central bank's fixing, by Frankfurter provider key (e.g. ECB, FRED, BOE); default: Frankfurter's blend of every bank that publishes the pair. Pattern `^[A-Za-z0-9_]{2,16}$`. |

## Frankfurter Rate History [#history]

`frankfurter/history` · **$0.001** per call (local) · Finance & Markets

**Daily, weekly or monthly exchange-rate history for up to 90 days, with change and range.**

A rate series from one currency to up to 5 others between two dates (at most 90 days apart), one point per day, week or month, plus a per-currency summary: first and last value, % change, low and high. The default blend includes weekend points from banks that publish then; provider=ECB gives business days only. For today's rate use frankfurter/rates.

Related: [`frankfurter/rates`](/docs/tools/frankfurter#rates), [`hako/fx`](/docs/tools/hako#fx).

### Input [#history-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `base` | string | no | ISO 4217, e.g. USD 3–3 characters. Pattern `^[A-Za-z]{3}$`. Default `"EUR"`. |
| `quotes` | array of string | yes | 1–5 items. Each item: 3–3 characters. Pattern `^[A-Za-z]{3}$`. |
| `start` | string (date) | yes | First day, YYYY-MM-DD. |
| `end` | string (date) | no | Last day (default: today; at most 90 days). |
| `group` | string | no | One point per day, week or month. One of `day`, `week`, `month`. Default `"day"`. |
| `provider` | string | no | One central bank's fixing, by Frankfurter provider key (e.g. ECB, FRED, BOE); default: Frankfurter's blend of every bank that publishes the pair. Pattern `^[A-Za-z0-9_]{2,16}$`. |

## Frankfurter Exchange Rates [#rates]

`frankfurter/rates` · **$0.001** per call (local) · Finance & Markets

**Latest or historical exchange rates from a base currency to up to ten others, from central banks.**

Rates from one currency to up to ten others, latest or as of a date, each with the date it was published. By default Frankfurter blends every central bank that publishes the pair (wide coverage, including weekends where some bank publishes); name a provider such as ECB for one bank's official fixing. Reference rates, not tradable quotes. For a single conversion use frankfurter/convert; for a series use frankfurter/history; for rates cross-checked across several banks with an agreement verdict use hako/fx.

Related: [`frankfurter/convert`](/docs/tools/frankfurter#convert), [`frankfurter/history`](/docs/tools/frankfurter#history), [`hako/fx`](/docs/tools/hako#fx).

### Input [#rates-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `base` | string | no | ISO 4217, e.g. USD 3–3 characters. Pattern `^[A-Za-z]{3}$`. Default `"EUR"`. |
| `quotes` | array of string | yes | Currencies to price. 1–10 items. Each item: 3–3 characters. Pattern `^[A-Za-z]{3}$`. |
| `date` | string (date) | no | Rates published on or before this day (default: latest). |
| `provider` | string | no | One central bank's fixing, by Frankfurter provider key (e.g. ECB, FRED, BOE); default: Frankfurter's blend of every bank that publishes the pair. Pattern `^[A-Za-z0-9_]{2,16}$`. |
