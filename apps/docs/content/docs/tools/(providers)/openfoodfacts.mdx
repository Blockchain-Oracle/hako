## Open Food Facts Product [#product]

`openfoodfacts/product` · **$0.001** per call (local) · Science & Health

**A packaged food by barcode: name, brand, Nutri-Score, NOVA group, ingredients, allergens, nutrition.**

Looks up one product in the crowd-sourced Open Food Facts database by its EAN/UPC barcode and returns name, brand, quantity, Nutri-Score (a–e), NOVA processing group (1–4), Eco-Score, ingredients text, allergens and traces, labels, categories and key nutrients per 100 g. Data is entered by volunteers and can be incomplete; it is not medical or allergy advice, so check the package. Unknown barcodes answer found=false. To find a barcode from a name use openfoodfacts/search.

Related: [`openfoodfacts/search`](/docs/tools/openfoodfacts#search).

### Input [#product-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `barcode` | string | yes | The EAN/UPC barcode digits, e.g. '3017624010701'. Pattern `^\d{8,14}$`. |

## Open Food Facts Search [#search]

`openfoodfacts/search` · **$0.001** per call (local) · Science & Health

**Search packaged food products by name or brand: barcode, brand, quantity, Nutri-Score, NOVA group.**

Full-text search over Open Food Facts products (Search-a-licious), returning barcodes to pass to openfoodfacts/product for ingredients, allergens and nutrition. Results are ranked by text match across names, brands and categories, worldwide. Open Food Facts allows 10 searches per minute, so prefer one precise query over many. It does not compare prices or availability.

Related: [`openfoodfacts/product`](/docs/tools/openfoodfacts#product).

### Input [#search-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | string | yes | Product or brand words, e.g. 'greek yogurt'. 2–200 characters. |
| `limit` | integer | no | From 1 to 20. Default `5`. |

### Example [#search-example]

```json title="Input"

  "limit": 5
}
```

```json title="Pay and run it with PayBox (use_service)"
  "method": "POST",
  "body": {
    "query": "greek yogurt",
    "limit": 5
  }
}
```
