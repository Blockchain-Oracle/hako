## Serper Google Images [#images]

`serper/images` · **$0.005** per call (standard) · Web Search

**Google Images results: direct image URL, thumbnail, size and the page it appears on.**

Image search through Google. Each result has the full-size image\_url, a thumbnail\_url, the pixel size, the title and url of the page that hosts it, and that site's name. It does not download, describe or check the licence of images: check the hosting page before reusing one.

Related: [`serper/search`](/docs/tools/serper#search).

### Input [#images-input]

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `query` | string | yes | What to search for; Google operators such as site:, quotes and - work. 1–400 characters. |
| `num` | integer | no | Results to return. From 1 to 10. Default `8`. |
| `country` | string | no | Two-letter country to search from, e.g. 'us', 'ng' (Google's gl). Pattern `^[A-Za-z]{2}$`. |
| `language` | string | no | Result language, e.g. 'en', 'fr', 'pt-br' (Google's hl). Pattern `^[A-Za-z]{2,3}(-[A-Za-z]{2,4})?$`. |

## Serper Google News [#news]

`serper/news` · **$0.005** per call (standard) · News

**Google News results: headline, publisher, how long ago, snippet and link.**

Searches Google News live. Each article has its headline, link, publisher (source), a relative date such as '3 hours ago' and a snippet. Set time\_range to 'day' for breaking stories. It returns headlines, not article bodies: open one with jina/read; for a cited summary of a story use hako/answer.

Related: [`jina/read`](/docs/tools/jina#read), [`serper/search`](/docs/tools/serper#search), [`hako/answer`](/docs/tools/hako#answer).

## Serper Google Places [#places]

`serper/places` · **$0.005** per call (standard) · Maps & Places

**Local businesses from Google Maps: name, address, rating, review count, category, phone, website, coordinates.**

Finds businesses and points of interest the way Google Maps does: give what you want and, ideally, a location in words. Each place has its name, address, category, star rating and number of ratings, price level, phone, website, latitude/longitude and a Google Maps link. It does not return opening hours or reviews. To turn a city name into coordinates use openweather/geocode.

Related: [`openweather/geocode`](/docs/tools/openweather#geocode), [`serper/search`](/docs/tools/serper#search).

## Serper Google Scholar [#scholar]

`serper/scholar` · **$0.005** per call (standard) · Research & Papers

**Google Scholar results: paper titles, authors and venue, year, citation count and PDF links.**

Searches Google Scholar by keyword and returns each paper's title, link, the author/venue line Scholar prints, year, how many times it is cited and a free PDF link when Scholar knows one. Keyword ranking, citation-weighted, no abstracts. For meaning-based search over abstracts use firecrawl/research-papers, then firecrawl/read-paper for the passages inside a paper.

Related: [`firecrawl/research-papers`](/docs/tools/firecrawl#research-papers), [`firecrawl/read-paper`](/docs/tools/firecrawl#read-paper), [`serper/search`](/docs/tools/serper#search).

## Serper Google Search [#search]

`serper/search` · **$0.005** per call (standard) · Web Search

**Google web results as JSON: titles, links, snippets, plus the answer box and knowledge panel.**

Runs a live Google search and returns the organic results (title, url, snippet, date) together with Google's own answer box and knowledge panel when it shows one, 'people also ask' questions and related searches. Snippets only: it does not open the pages. Read a result with jina/read; get every result's page text in one call with jina/search; for a written answer with citations use hako/answer.

Related: [`hako/answer`](/docs/tools/hako#answer), [`jina/read`](/docs/tools/jina#read), [`jina/search`](/docs/tools/jina#search), [`serper/news`](/docs/tools/serper#news).
