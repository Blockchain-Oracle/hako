The catalog has **80 tools** from **33 providers**. A tool's id is `provider/endpoint`. Each tool has a fixed price per call, an input JSON Schema, an output schema and a working example.

These pages are a snapshot of the catalog (hash `3dad12ebd17641d7`). The live list is `GET https://api.usehako.xyz/v1/catalog`, and [discover](/docs/api/discover) ranks it for a job. Health (status, p50, p95) is live data, so it appears only in discover results, not here.

## How prices work

Each tool has one of three prices. You pay per successful run, in USDC on Base, with your PayBox wallet over x402. Discover and inspect are free. A run that fails, or a lookup that finds nothing, is never charged. See [Pricing and payments](/docs/pricing).

| Tier | Price per call | Atomic units | For | Tools |
| --- | --- | --- | --- | --- |
| `local` | $0.001 | `1000` | Keyless upstreams and local compute. | 52 |
| `standard` | $0.005 | `5000` | Keyed upstreams that are cheap per call. | 24 |
| `premium` | $0.01 | `10000` | Upstreams that cost $0.005 or more per call, or several chained calls: live search with page content, cited answers. | 4 |

Premium tools: [`firecrawl/ask-page`](/docs/tools/firecrawl#ask-page), [`firecrawl/search`](/docs/tools/firecrawl#search), [`hako/answer`](/docs/tools/hako#answer), [`jina/search`](/docs/tools/jina#search).

USDC has 6 decimals, so 1000 atomic units are $0.001. The 402 response states the exact amount for each run.

## Run any tool

```bash
npx -y usehako inspect openweather/current
```

`inspect` returns the tool's input schema, its example and its `paidUrl`. Your PayBox agent pays and runs it with PayBox's `use_service`: that URL, method `POST`, the tool's input as `body`, and your Base wallet's `credential_id` from `list_credentials`.

```json title="use_service"
{
  "url": "https://api.usehako.xyz/v2/run/openweather/current",
  "method": "POST",
  "body": {
    "city": "Lagos,NG",
    "units": "metric"
  }
}
```

Over plain HTTP, `POST /v2/run/{provider}/{endpoint}` answers `402` with the exact price until it is paid; see [Run](/docs/api/run).
