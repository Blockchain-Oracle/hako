---
title: In the browser (agent chat)
description: Try Hako without installing anything. A chat agent finds tools and reads their contracts for you; paid runs use your PayBox wallet.
---

Open [`https://usehako.xyz/agent`](https://usehako.xyz/agent) and ask for a tool for a job, for example "Which tool tells me if it is raining in Lagos right now, and what does it cost?".

The agent works the same way any Hako client does. It searches the catalog and reads the contract of the tool it picked. Each step shows in the conversation.

## Paid runs

Without a connected wallet the chat is **Not connected**: discover and inspect work, and a paid run tells you it needs PayBox. Hako never pays for you and holds no key. **Connect PayBox** in the web app is being built; until it ships, run a tool through your own PayBox agent with `use_service` on the tool's paid URL (see [Quickstart](/docs/quickstart#paying-for-a-run)).

## When to move on

To give your own agent the same tools, use the [Skill](/docs/quickstart/skill), [MCP](/docs/quickstart/mcp) or the [CLI](/docs/quickstart/cli).
