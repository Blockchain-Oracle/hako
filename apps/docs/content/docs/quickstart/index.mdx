## Paying for a run

Every tool's paid URL is `https://api.usehako.site/v2/run/<provider>/<endpoint>`. With PayBox connected to your agent (Claude, ChatGPT, Cursor or any PayBox host), ask it to run the tool: it calls PayBox's `use_service` with that URL, method `POST` and the tool's input as the body. PayBox pays the exact price in USDC on Base from your wallet, after your approval when your grant asks for one, and returns the answer.
