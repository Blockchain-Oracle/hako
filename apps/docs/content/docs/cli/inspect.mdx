---
title: inspect
description: One tool's full contract, its description, input JSON Schema, output schema, price and a working example, plus the paid URL your PayBox wallet pays. Free.
---

```bash
npx -y usehako inspect <provider/endpoint>
```

It calls [`POST /v1/inspect`](/docs/api/inspect) with `{id}`, adds the tool's paid URL, and prints the result. An unknown id fails with `unknown_endpoint` and exit code 1.

## Example

```bash
npx -y usehako inspect openweather/current
```

The result has every `discover` field except `score` and `health`, plus:

| Field | Meaning |
| --- | --- |
| `description` | What the tool does, what it will not do, and what to call instead |
| `notes` | Extra notes for the agent |
| `seeAlso` | Related tool ids |
| `deadlineMs` | The run deadline for this tool |
| `cacheTtlS` | How long a result is cached, in seconds (`null`: not cached) |
| `terms` | How the provider's terms classify the data |
| `input` | The input JSON Schema. Unknown fields are rejected. |
| `output` | The JSON Schema of `data` in a successful run |
| `example` | A valid input; it is also the tool's live probe |
| `paidUrl` | Where a run is paid: `https://api.usehako.site/v2/run/<provider>/<endpoint>` (from `HAKO_API_URL`) |
| `howToPay` | One line saying how: USDC on Base (`eip155:8453`) from your PayBox wallet, through PayBox's `use_service` with that URL, method `POST` and the input as body |

Read `input` before a run. Copy `example` as a starting point:

```bash
npx -y usehako inspect openweather/current | jq -c '{paidUrl, example}'
# {"paidUrl":"https://api.usehako.site/v2/run/openweather/current","example":{"city":"Lagos,NG","units":"metric"}}
```
