# Provenance of the marks in `svg/`

Every file here is either a first-party brand asset or a redrawn mark from an open icon set (web3icons, MIT;
simple-icons, CC0; circle-flags, MIT), named in its row. Most rows come from Kawase's identity package
(`tamion/packages/identity/PROVENANCE.md`, the owner's own project) with Hako's entity keys; the rest were retrieved
for Hako on 2026-10-17. One row per file. Add a row before adding a file; `build.mjs` turns each file into a DOM
component. Real marks are never tinted: only `-mono` files take `currentColor`.

Brands named here remain their owners' trademarks and are shown only to identify the service, chain or token.
